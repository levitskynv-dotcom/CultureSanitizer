# CultureSanitizer (v13/v14 для Bannerlord 1.5.7)

Набор мелких стабилизирующих патчей для Mount & Blade II: Bannerlord.
Лечит вылеты и зацикливания в кампании, следит за здоровьем сейва и
помогает находить конфликты между модами.

## Что делает

- **SiegeGuard** — защита от вылета при взятии поселения. Ванильная
  гонка таймингов: осаждающая партия уже покинула поселение, а меню
  «settlement taken» ещё срабатывает. Гард перехватывает оба варианта
  меню (army_member и participant), проверяет осаждавшего и безопасно
  закрывает энкаунтер вместо падения.
- **CultureSanitizer** — санитар кампании: чистит битые записи культур
  и заказов на ковку, аудит пулов владельцев заказов при загрузке
  (нотабли, герои без партий), битые записи логируются.
- **StackSentinel** — защита от зацикливания русского текстового
  процессора (`LanguageSpecificTextProcessor`): рекурсия валилась в
  StackOverflow при загрузке/в обработке локализации.
- **Диагностика Harmony** — при загрузке сейва пишет в лог все методы,
  которые патчат два и более модов одновременно. Полезно для больших
  сборок модов: конфликт виден сразу, а не как «иногда вылетает».

## Версия игры

Собрано под **Bannerlord 1.5.7**. На других версиях не проверялось —
сигнатуры методов движка различаются между версиями.

## Зависимости

- [UIExtenderEx](https://www.nexusmods.com/mountandblade2bannerlord/mods/2102)
- Требуется .NET Framework 4.8 (стандартно для игры)

## Установка

1. Установите Harmony и UIExtenderEx.
2. Скопируйте папку `CultureSanitizer` в `Modules`.
3. Включите мод в лаунчере.

## Сборка из исходников

Требуется .NET SDK (dotnet 6+ работает; целевой фреймворк — net48).
